# راه‌اندازی پایلوت تک‌فروشنده DigiPrice

## دامنه این نسخه
- ذخیره کاتالوگ در Microsoft SQL Server Enterprise.
- ورود گروهی کالاها با CSV، ویرایش کالاها در داشبورد و محاسبه پیشنهاد قیمت.
- تمام پیشنهادها صرفاً شبیه‌سازی هستند. هیچ اتصال یا نوشتن قیمت در دیجی‌کالا فعال نیست.
- این نسخه برای تست محلی/شبکه خصوصی کنترل‌شده است؛ تا پیش از احراز هویت و ممیزی امنیتی، روی اینترنت عمومی منتشر نشود.

## 1) ساخت دیتابیس و جدول‌ها
1. در SSMS یک دیتابیس خالی با نام `DigiPrice` بسازید.
2. فایل `database/001-initial-schema.sql` را در همان دیتابیس اجرا کنید.
3. حساب Windows یا حساب سرویس برنامه را با حداقل مجوز لازم تنظیم کنید. برای نصب اولیه مجوزهای DDL لازم است؛ برای اجرای روزمره بهتر است مجوزهای برنامه به عملیات لازم محدود شود.
4. رشته اتصال را با متغیر محیطی `ConnectionStrings__DigiPrice` تنظیم کنید. نمونه Windows Authentication:
   `Server=SQLSERVER01;Database=DigiPrice;Integrated Security=True;Encrypt=True;TrustServerCertificate=False`
5. از گواهی TLS معتبر SQL Server استفاده کنید. رمز عبور یا رشته اتصال عملیاتی را وارد Git نکنید.

## 2) اجرا
از ریشه مخزن، با .NET SDK 10:

```powershell
$env:ConnectionStrings__DigiPrice = "Server=SQLSERVER01;Database=DigiPrice;Integrated Security=True;Encrypt=True;TrustServerCertificate=False"
dotnet run --project src/DigiPrice.Api
```

فقط روی همان رایانه و در مرورگر محلی باز کنید، مگر آنکه دسترسی شبکه با کنترل‌های امنیتی جداگانه محدود شده باشد. در شروع، برنامه اتصال SQL Server و وجود جدول `dbo.Products` را بررسی می‌کند و دیتابیس را خودکار ایجاد/بازسازی نمی‌کند.

## 3) ورود کالاها
در داشبورد روی «ورود گروهی CSV» کلیک کنید و فایل آماده‌شده با قالب `database/product-import-template.csv` را تکمیل کنید.

ستون‌ها:
- `sellerSku`: شناسه یکتای کالا در فهرست شما؛ مقایسه بدون حساسیت به بزرگی/کوچکی حروف است.
- `title`: عنوان کالا.
- `currentPriceToman`: قیمت فعلی به تومان.
- `costPriceToman`: بهای تمام‌شده به تومان.
- `minPriceToman` و `maxPriceToman`: کف و سقف مجاز به تومان؛ قیمت فعلی هم باید داخل این محدوده باشد.
- `competitorPriceToman`: قیمت مرجع رقیب به تومان؛ اگر نامشخص است، خالی بگذارید.
- `strategy`: یکی از `UndercutCompetitor`, `MaximizePriceWithinLimits`, `FixedPrice`, `Defensive`.

قیمت‌ها باید عدد صحیح بدون جداکننده هزارگان باشند؛ نمونه: `1250000`. فایل UTF-8 و جداکننده ستون‌ها ویرگول انگلیسی باشد. کالاهای موجود با همان SKU به‌روزرسانی می‌شوند؛ کالاهای جدید در حالت غیرفعال/تأیید دستی ایجاد می‌شوند. سطرهای نامعتبر گزارش می‌شوند و سایر سطرهای معتبر ذخیره می‌شوند.

## 4) آزمون پیشنهادی
1. ابتدا 5 تا 10 کالای کم‌ریسک وارد کنید.
2. صحت قیمت جاری، بهای تمام‌شده، کف و سقف را با پنل فروشنده مقایسه کنید.
3. قیمت رقیب را دستی از منبع قابل‌مشاهده و مجاز ثبت کنید؛ این نسخه قیمت رقیب را خودکار جمع‌آوری نمی‌کند.
4. برای هر کالا «شبیه‌سازی قیمت» را اجرا و پیشنهاد و هشدارها را بررسی کنید.
5. در پایان برنامه را متوقف و دوباره اجرا کنید و ماندگاری اطلاعات را بررسی کنید.
6. هیچ پیشنهادی به‌صورت خودکار به دیجی‌کالا ارسال نمی‌شود.

## محدودیت‌های شناخته‌شده
این پایلوت هنوز احراز هویت/نقش کاربری، ثبت تاریخچه پیشنهادها، همگام‌سازی مجاز دیجی‌کالا، واردسازی مستقیم از فایل خروجی فروشنده با نگاشت اختصاصی، مهاجرت خودکار schema و تغییر قیمت زنده ندارد. تا پیش از اضافه شدن احراز هویت، فقط در محیط کنترل‌شده و بدون دسترسی عمومی اجرا شود.
