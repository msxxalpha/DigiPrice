# DigiPrice

سامانه هوشمند قیمت‌گذاری برای فروشندگان مارکت‌پلیس دیجی‌کالا؛ با تمرکز بر حفاظت از سود، رقابت کنترل‌شده و اجرای ترکیبیِ تأیید دستی/خودکار.

> **وضعیت فعلی: MVP پایه در حالت شبیه‌سازی.** این نسخه موتور قیمت‌گذاری، API و داشبورد اولیه را فراهم می‌کند. هنوز به حساب واقعی دیجی‌کالا متصل نیست و هیچ قیمت واقعی را تغییر نمی‌دهد. اتصال و نوشتن قیمت تنها پس از اعتبارسنجی مستندات، مجوزها، امنیت و آزمون واقعی اضافه خواهد شد.

## قابلیت‌های این مرحله

- موتور مستقل قیمت‌گذاری با استراتژی‌های رقابت محدود، حداکثرسازی قیمت در محدوده، قیمت ثابت و محافظه‌کار.
- کنترل کف و سقف قیمت، محدودیت تغییر نسبت به قیمت جاری و هشدار در صورت حاشیه سود ناخالص منفی.
- API نمونه برای فهرست و ثبت کالا و پیش‌نمایش قیمت پیشنهادی.
- داشبورد فارسی و راست‌چین برای مشاهده کالاها و اجرای شبیه‌سازی.
- تست واحد و گردش‌کار CI برای build/test.
- داده‌های اولیه فقط نمونه‌اند و در حافظه نگهداری می‌شوند؛ با restart از بین می‌روند.

## فناوری‌ها

- .NET 10 / ASP.NET Core Minimal API
- کتابخانه دامنه C# مستقل از وب
- رابط کاربری سبک HTML/CSS/JavaScript
- xUnit برای تست‌های واحد
- GitHub Actions برای اعتبارسنجی build و test

## اجرای محلی

پیش‌نیاز: .NET SDK 10.

از ریشه مخزن اجرا کنید:

```bash
dotnet run --project src/DigiPrice.Api
```

سپس نشانی‌ای را که در خروجی ترمینال نمایش داده می‌شود باز کنید. API سلامت در مسیر `/api/health` و فهرست کالاها در `/api/products` در دسترس است.

اجرای تست‌ها:

```bash
dotnet test tests/DigiPrice.Core.Tests
```

## اصول ایمنی قیمت‌گذاری

1. نسخه فعلی فقط پیشنهاد قیمت می‌دهد؛ اجرای واقعی غیرفعال است.
2. قیمت‌ها به‌صورت عدد صحیح **تومان** ذخیره و محاسبه می‌شوند.
3. قیمت پیشنهادی همیشه با کف و سقف تعریف‌شده اعتبارسنجی می‌شود.
4. قیمت رقیب ناموجود به‌عنوان صفر یا قیمت معتبر فرض نمی‌شود.
5. هر پیشنهاد نیازمند تأیید است؛ وضعیت «اتوپایلوت» در MVP فقط تنظیم آینده را نمایش می‌دهد و سفارش واقعی ارسال نمی‌کند.
6. توکن‌ها، کلیدهای خصوصی و اطلاعات ورود فروشنده نباید در مخزن، log یا رابط کاربری ذخیره شوند.
7. قبل از استفاده تجاری باید احراز هویت، جداسازی tenant، ذخیره‌سازی پایدار، رمزنگاری اسرار، محدودسازی نرخ، ممیزی امنیتی و اتصال مجاز به API پیاده‌سازی شوند.
